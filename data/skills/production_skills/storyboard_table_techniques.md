# 分镜表通用技法

本文档为分镜表设计的通用技法参考，适用于所有需要构建分镜表的 Agent 场景。

本技法服从全局约束、已确认任务与分镜执行契约。镜头数量、6秒/12秒、字数等是节奏参考，不是额外硬上限；制作预算和片段15秒限制以执行契约为准。技法不得改变原台词、事件因果、当前有效资产或 XML/Markdown 格式。

---

## 分镜拆分原则

**新起分镜**：时空变化、需要改变观察位置、关键动作或信息揭示无法在当前构图中看清时拆镜；主体或景别变化本身不自动要求切镜。

**不需新起**：同画面内连续对话、表情微变或小动作

粒度：一个独立画面对应一条分镜，依据动作节点、信息变化和预算拆分，不按每50–100字机械换镜。过渡/转场仅在有明确叙事需要时单独拆分。

每条数据行对应一个连续镜头。实际剪辑切镜时，切前与切后各自另起一行并分配时长；反打、插入特写同样如此。连续运镜只写不间断路径，不在运镜列或画面描述中隐藏“硬切→下一机位”的多镜头链。一片段可含多行，合计仍不超过 15 秒。

## 定场与镜头合并规则（防冗余）

**定场镜头**：根据观众已经知道的空间决定是否定场，通常 1~2 镜足够。需要交代危险方向、出口或人物关系时才补充，不因换段落重复展示同一空间。
- 推荐做法：1 个带缓推的远景（定场+主体引入一镜完成），或 1 个大远景定场 + 1 个全景引入主体
- 环境、细节、人物到达若没有各自的新信息，应合并；各自承担铺垫、揭示或反应时可以保留。

**镜头合并自检**：
- 能一镜交代的不拆两镜——如果一个带运镜的镜头能同时完成定场+引入，不要拆成两个
- 连续描述同一空间不同局部的镜头（院门→藤蔓→厢房）应合并为一个镜头，用画面描述涵盖多层空间
- 纯装饰性镜头（只展示环境细节无叙事推进）应合并到有叙事功能的镜头中
- **合并依据**：相邻镜头承担同一任务、同一视点且没有新信息或表演变化时优先合并；揭示与听者反应需要不同视点时保留切镜。

**一镜到底策略**：当相邻镜头之间存在**动作连续变化、场景轻度变化（同场景内位移）、或拍摄角度渐变**时，可在 `cameraMove` 或 `description` 中标注「一镜到底」，将多个碎片镜头合为一个连续运镜长镜头。
- **适用场景**：角色行走穿越空间、跟随动作从A点到B点、环绕角色展示环境、定场缓推到主体特写等
- **标注方式**：在 `cameraMove` 中写明运镜路径（如"一镜到底：缓推远景→跟移至院内→落幅全景"），在 `description` 中描述起幅和落幅的画面内容
- **时长分配**：一镜到底按动作与信息变化分配预算；6秒/12秒是常见节奏参考，硬限制来自本片段预算及执行契约，不与下文8秒经验值叠加成不同上限
- **风险提示**：一镜到底会提高画面生成的抽卡难度（连续性要求高），仅在叙事流畅性收益明显大于碎切时使用，不滥用

**停留自检**：无台词镜头超过 6s 时检查是否仍在完成等待、判断、情绪消化或信息阅读；有明确任务可以停留，没有变化和回报则压缩。6s 不是镜头硬上限。

## 视觉连续性铁律（分镜设计时全程遵守）

**① 动作连续性**：相邻镜头间角色的位置、动作进度、朝向必须物理逻辑一致。上一镜手伸到半空→下一镜必须从半空状态接续，不能突然收回。

**② 景别服务注意力**：按本镜需要确认的动作、关系或细节选择景别。渐进聚焦或释放是可选方法——
- 渐进聚焦：远景→全景→中景→近景→特写（情绪收紧）
- 渐进释放：特写→近景→中景→远景（情绪释放）
- 可以由全景直接切关键接触特写，也可以连续同景别表现对峙；切换须有信息或表演理由，不按数量强制换景别。

**③ 视轴守恒**：对话/对峙中保持世界位置与视线轴线；机位移动、反打或明确越轴后，按实际观察方向推导画面左右，不要求角色全片固定同侧。没有依据的跳轴或位置瞬移须修正。

**④ 朝向空间逻辑**：对话双方面朝彼此，操作物品面朝物品，注视远方面朝远方。禁止无差别面朝镜头

**⑤ 信息控制意识**：每镜须意识到"观众此刻知道什么、不知道什么"——
- 给手不给脸 = 悬念；先声后画 = 期待；只给背影 = 疏离；全貌揭示 = 高潮兑现

**⑥ 动作与时间可行性**：每镜承担一个主要戏剧任务，允许同一任务下可读的连续动作链。对白、视线和兼容动作可以并行；必须先完成的接触、失衡、阅读或反应按真实先后留时间，不把每次运镜、动作和台词各算一拍后机械相加。复杂链条看不清或预算不足时在因果节点拆镜。

**⑦ 镜头衔接**：切点由动作、台词、视线或局势变化决定；有需要才为起势、停顿和收势留时间。不中断关键接触或吞掉反应，不为每镜强制预留首尾各 0.5s，也不让人物等待空白后才开始讲话。

## 字段填写指引

当前输出仅有「序号、画面描述、时长、景别、运镜、台词、音效」七列。下述语义写入对应列、场标题或片段引用清单，不新增 action、orientation、spatialRelation、emotion 等列，也不输出这些内部字段名。

**description**（画面描述）：紧凑说明可见的**主体 + 动作/状态 + 环境空间**，不写不可见心理。复杂接触和支撑关系允许多句，不以固定字数删事实；空间层次按本镜需要表达，特写不强行添加背景事件。例句只能说明结构，不能作为项目事实。

> **照明与渲染**：身份、衣装和空间结构来自当前有效资产；渲染沿用已确认项目目标。可简写符合本场时段、天气和已有光源的受光、阴影及材质关系，用于看清表演与空间；不凭空增设光源或改变场景状态。屏幕亮起、闪光等原文事件保留。需要独立复用的新场景状态时反馈衍生需求，不在此阶段创建资产。

**shotSize**（景别）：

| 景别 | 说明 | 叙事语义 |
|------|------|---------|
| 大远景 | 环境全貌 | 定场 / 孤独 / 渺小 |
| 远景 | 场景与人物关系 | 空间关系 / 氛围渲染 |
| 全景 | 人物全身与环境 | 角色登场 / 全身亮相 |
| 中景 | 膝盖以上 | 日常叙事 / 对话 |
| 近景 | 胸部以上 | 情感传达 / 对话重点 |
| 特写 | 面部或物件局部 | 情绪强化 / 关键道具 |
| 大特写 | 极致局部 | 情绪核弹 / 决定性瞬间（慎用，全片 2~3 次） |

**cameraMove**（运镜）：无运镜时填 `静止`。运镜须标注起终点方向。

| 运镜 | 说明 | 叙事语义 |
|------|------|---------|
| 推 | 从远到近，强调主体 | 情绪递进 / 发现 / 窥视 |
| 拉 | 从近到远，展示环境 | 情绪抽离 / 揭示全貌 / 离别 |
| 摇 | 固定位置旋转扫视 | 环境交代 / 搜索 |
| 移 | 跟随主体移动 | 陪伴 / 追踪 |
| 俯拍 | 从上往下 | 旁观 / 渺小 / 全局 |
| 仰拍 | 从下往上 | 英雄化 / 威压 |

**画面描述中的动作、朝向、空间与情绪**：
- 写明开始状态、谁对谁做什么、接触点和支撑变化、可见结束状态；静止、等待或判断本身有戏剧功能时不强加动作链。
- 按本镜机位交代必要位置与视线。世界位置稳定，屏幕左右可随反打改变；身体真正转向或移动才写动作衔接，不为换景别伪造转身。
- 情绪通过目光、呼吸、停顿、重心或动作选择表达，不能只写“更紧张、更震撼”。不固定字数，不复制与本镜无关的站位表或人物例名。

**场景名称**：写在场标题，与剧本对应，不新增 scene 列。

**引用资产名称**：写在片段清单，包括实际可见的角色、场景和物件；ID 使用当前资产真实值。

**duration**：基础参考——特写/表情 2~3s · 对话近景 3~5s · 全身亮相 3~5s · 动作 2~4s · 远景/空镜/过渡 3~5s · 复杂场景 5~8s。按实际对白、动作与制作预算调整，不把8秒当硬上限；每片段时长与逐场/全片预算须符合执行契约。

**含台词时，时长必须足够念完全部台词且匹配情绪语速**：

| 情绪状态 | 语速参考 | 示例场景 |
|---------|---------|----------|
| 愤怒、急促、争吵 | ~4 字/秒 | 怒斥、催促、惊慌 |
| 正常对话、叙述 | ~3 字/秒 | 日常交谈、冷静陈述 |
| 悲伤、深情、沉思 | ~2 字/秒 | 告白、哀悼、回忆 |
| 低语、虚弱、临终 | ~2 字/秒 | 气若游丝、耳边呢喃 |

计算方式：有配音时优先实测；上表仅用于中文初估，其他语言按词数和实际语速估算。停顿依语义与表演，不按每个标点机械累加；必要串行动作另计，可并行的动作与讲话共用时间。
- 标点用于识别可能停顿，不能直接当作固定0.3~0.5s时长
- 情绪转折和语气变化有真实停顿时再计时，已包含在配音里的停顿不重复计算
- 最终 `duration` 同时覆盖可听清对白与必要动作，并与本场预算核对；估算留余量不能靠每镜强加1秒使整场超时

**台词**：原文逐字保留，说话人和对话先后不变，多角色按 `角色名：台词` 排列，无台词填 `无台词`。切镜取决于揭示、反应、动作与时长；同一构图内的短对话可共镜，长对白可按语义停顿跨镜，不机械一句一镜。

**sound**（音效）：纯音效描述，按「环境音层 + 动作音层」分层。如"远处风声呼啸 + 剑鸣声"。无音效填 `无音效`。

> **🚫 严禁音乐/配乐**：本流水线最终产物**完全不含背景音乐**。`音效` 列只承载真实声源（环境音 + 动作音 + 拟音），任何"BGM""配乐""旋律""管弦/钢琴/竖琴/笛声等乐器作为氛围烘托"等字样**一律违规**，审核会判严重问题。如剧本中出现乐器演奏作为剧情动作（如角色弹琴），仅可写"指尖拨弦的金属振动声 + 共鸣箱嗡鸣"等具体物理音源。

**associateAssetsIds**：画面中**可见的**资产的 ID（从 assets 数据中获取的实际 `id` 字段值），不编造不存在的 ID。
- **角色出现即引用**：画面中出现的所有角色，无论是主体还是仅局部可见（如背影、手部、虚化剪影等），只要在画面内可被辨识，都必须引用其对应的资产 ID
- **场景资产必选**：每条分镜必须引用其所处场景对应的场景资产 ID（type 为 scene 的资产）；若该场景存在匹配当前画面状态的衍生场景资产，则选用衍生场景资产 ID，否则选用主场景资产 ID。缺少场景资产 ID 视为字段不完整
- 父子资产选择规则：按剧情画面所需状态选择资产 ID——若该镜头需要某主资产的衍生状态，**只选衍生资产 ID**；仅当不存在匹配的衍生状态时，才选择主资产 ID；同一父资产在同一分镜中禁止主/衍生同时出现

## 转场规则

- **同场戏内**：镜头间默认硬切
- **跨场景**：默认可直切。只有需要交代时空或连接情绪时才用已有环境、动作或声音衔接，并计入预算；不强制空镜或补出原文没有的地点和事件。
- **跨段落**：可在 description 中标注"叠化过渡"或"淡入淡出"
- 禁用花式转场（划屏、旋转、百叶窗等）
