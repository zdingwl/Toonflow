# 全局美学基础 · 真人3D动漫

必须完整遵循下列风格约束。最终提示词只描述可见画面，不解释规则，不输出标题、注释或创作过程。

## 一、核心风格基因

| 维度 | 定义 |
|---|---|
| 一级风格 | 真人3D动漫（Realistic 3D Anime） |
| 人物结构 | 成年真人骨相、自然体态与准确关节，克制的动漫化五官归纳 |
| 渲染媒介 | 高品质 3D CGI、PBR 材质、全局光照、皮肤次表面散射、发丝级毛发 |
| 画面气质 | 电影动画质感、真实可信、精致但不过度修饰 |
| 识别边界 | 明确为 3D 动画，不得伪装成真人照片或退化为平面二次元 |

## 二、全局硬约束

1. 每条提示词必须包含“真人3D动漫、高品质 3D CGI、真人骨相与自然人体比例”。
2. 人脸必须同时具备真实颅面结构、自然皮肤微纹理与克制动漫化设计；眼睛仅轻度放大，虹膜、眼睑和视线真实。
3. 皮肤使用自然毛孔、细微绒毛、合理油脂与次表面散射，保留年龄和生活状态，禁止陶瓷或蜡像皮肤。
4. 头发使用发束加细发丝层级，发际线、重力、风向和高光合理，禁止整块塑料头发。
5. 服装、建筑和道具采用符合时代与功能的 PBR 材质，必须有真实厚度、接缝、褶皱、磨损与接触阴影。
6. 灯光必须有明确主光来源、环境反弹光和自然阴影；景深、镜头和调色服从叙事。
7. 同一角色跨资产和镜头保持脸型、五官距离、肤色、发型、体型及标志性细节一致。

## 三、色彩与光影

- 默认使用自然肤色、中等饱和度、受控高光与柔和的冷暖分离。
- 日景优先自然天空光与环境反射；夜景保留暗部细节，实景光源需有动机。
- 情绪可改变色温、光比与饱和度，但不得用无依据的霓虹溢色覆盖材质本色。
- 高光不过曝，黑位不死黑，轮廓光仅在场景存在合理逆光时使用。

## 四、统一负面约束

真人照片、实拍摄影、纯 2D 插画、平涂赛璐珞、Q 版、幼态大头、夸张巨眼、塑料玩偶、蜡像皮肤、过度磨皮、玻璃眼、低模、粗糙贴图、锯齿、穿模、漂浮、比例错误、额外肢体、错误手指、僵硬姿态、无来源轮廓光、过曝、死黑、过度 Bloom、文字、水印、logo、边框。
