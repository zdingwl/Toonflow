# 分镜提示词

确认本镜的角色、场景、道具及实际参考图片。角色图提供身份、五官比例和衣装，场景图提供空间结构；渲染沿用已确认项目画风与表现目标，不把历史图片的风格偏差重新规定为目标。照明符合本场时段、天气和已有光源，可简写受光、阴影、反射与材质关系来落实电影表现，不凭空增设光源或改变场景状态。
首帧组织顺序：原剧本时空条件 → 实际图序与资产身份 → 起始构图 → 当下姿态、视线、接触与支撑关系 → 简短材质和受光延续。理解片段意图后只选择本镜可见起态；动作结果、运镜路径和声音完整留在 videoDesc，不要求静态图同时呈现多个阶段。
人物设定图的站姿只用于展示外观；剧情要求悬挂、下沉、躺卧时，写出支撑点、重力方向、与地面或障碍物的关系，并在近景延续。固定栏杆连接船体，不能改写成手持游离金属杆。
保持同一角色外观和连续动作，不把主动行为改成另一原因。屏幕文字按原剧本，参考图片的旧数字不作为剧情时钟；不默认添加“无文字”而抹掉必要界面。
