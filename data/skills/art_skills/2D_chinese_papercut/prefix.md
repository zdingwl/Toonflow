# 全局美学基础 · 中国剪纸动画

必须严格、完整遵循本风格约束，并按调用方模板生成可直接用于图片/视频模型的提示词。默认只输出提示词正文，不输出规则解释。

## 一、风格基因

| 维度 | 定义 |
|---|---|
| 一级风格 | 中国剪纸动画（Chinese paper-cut animation） |
| 二级风格 | 民间剪纸 · 纸偶定格质感 |
| 情感基调 | 质朴、民俗、装饰性、节奏鲜明 |
| 质感锚词 | 可见纸纤维、剪切边缘、层叠纸片、关节式纸偶、轻微实体投影 |

## 二、全局视觉约束

- **角色**：角色以清晰剪影、侧面/半侧面轮廓和镂空纹样建立识别；肢体可采用纸偶关节结构，但比例必须稳定
- **场景**：二维舞台式分层空间，前中后景由纸片层级、遮挡和轻微投影区分；可吸收年画、皮影、民间纹样语言
- **道具**：功能造型以剪纸轮廓和镂空纹样表现，边缘切口与纸张层叠清晰，不伪装为塑料或3D模型
- **光影**：均匀柔光或背光纸影，强调纸片层次和边缘，不使用复杂镜头炫光
- **色彩**：朱红、墨黑、米白、土黄、靛青等民间色为基础，可按剧情扩展但避免荧光色
- **环境动态**：纸片云层、剪纸花叶、灯影、窗花投影、旗幡、纸屑/落叶

## 三、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 每条提示词必须明确「中国剪纸动画」风格锚点 |
| R2 | 媒介质感必须体现：可见纸纤维、剪切边缘、层叠纸片、关节式纸偶、轻微实体投影 |
| R3 | 角色、场景、道具跨图必须保持身份/结构连续性 |
| R4 | 光线、色彩、镜头必须服从当前剧情和情绪，不得为炫技而堆叠 |
| R5 | 用户未提供精确信息时，只用相对描述，不擅自编造身高、年代、品牌、色值或器物细节 |

- 不生成字幕、水印、标题卡、界面文字；剧情世界内确有标牌/书信时按剧情描述。
