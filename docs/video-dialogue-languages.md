# 视频对白语言版本

视频工作台 → 视频生成：在生成提示词之前，多选“对白语言”。选择按项目和剧集保存在数据库中。

- 单段“生成提示词”按当前视觉手册重新生成所选语言的提示词，成功后替换这些语言的旧提示词（包括人工编辑）；原版、其他语言和已有视频及其提示词快照保留。失败时保留旧文本并显示失败原因。
- “批量生成提示词”只补齐缺失或失败的语言，保留已完成的提示词（包括人工编辑）。
- 语言标签用于切换提示词、历史视频和选用的视频。选用一个语言版本不会替换原版选用的视频。
- 单段和批量生成都会为所选语言分别创建视频；提交前检查所有语言提示词是否就绪，并要求开启声音。确认窗口显示实际视频数量。
- 下载文件名包含语言代码。批量下载按当前查看的语言，下载所勾选视频段中已选用的版本。
- 取消语言勾选不会删除其提示词和视频，已生成版本仍可通过标签访问。

旧数据没有可靠的语言标记，统一显示为“原版（未标注语言）”，不自动猜测语言。

实现使用三张增量表：`o_videoLanguageSelection`、`o_videoPromptVariant`、`o_videoLanguage`。最后一张保存每次生成所用语言及提示词快照。迁移可重复执行，不覆盖旧数据。

本地 H3 的同一批次保持串行生成。语言作为翻译指令和视频提示词传递，实际发音、口型和语种支持取决于所选视频模型。翻译模型报告时长不足时，该语言标记失败，供用户人工检查并修改提示词；这不替代实际音视频验收。
