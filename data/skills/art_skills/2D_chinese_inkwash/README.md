# 中国水墨动画风格说明

本风格用于 Toonflow 的「中国水墨动画」视觉与导演约束，目录结构与现有 art_skills 保持一致。

## 核心风格
- **媒介定位**：2D；传统水墨语言 · 写意二维动画
- **情感基调**：含蓄、诗意、空灵、留白
- **核心质感**：墨分浓淡、宣纸晕染、干湿笔触、虚实边缘
- **色彩方向**：墨黑、灰墨、宣纸白为基底，青绿、赭石、朱砂等少量淡彩只作叙事点染
- **光影原则**：以明度、留白和淡彩表现光感，不使用写实CG体积光堆叠
- **镜头原则**：优先静镜、缓推、缓移、轻摇与长呼吸镜头；运镜须由人物行动、视线或空间揭示驱动

## 资产规则
- **角色**：以剪影、五官关键点、发型和服饰轮廓保持身份；轮廓不做机械硬描边，允许水墨边缘自然渗化
- **场景**：以留白、远近墨色层次、雾气与水面建立空间；前中后景通过墨色浓淡和虚实关系区分
- **道具**：以水墨笔触概括结构，材质通过干湿、浓淡、飞白和局部淡彩表达；功能轮廓必须清晰
- **环境动态**：云雾流动、水波、竹叶、飞鸟、雨丝、墨迹扩散

## 严禁
- 厚重硬描边
- 均匀赛璐璐平涂
- 3D塑料感
- 霓虹赛博色
- 过度锐化
- 满幅高饱和

## 研究依据
- 中国动漫博物馆：水墨动画将中国水墨画技法融入动画，强调宣纸晕染、虚实意境与轻灵画面。
- 参考：https://ccam.hzxcw.gov.cn/m/article/458.html

> 规则目标是提取可复用的媒介与摄影语言，不模仿具体在世创作者或单一工作室。
