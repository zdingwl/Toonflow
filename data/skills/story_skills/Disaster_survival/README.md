# 灾难求生 · 导演叙事手法技能包

## 简介
本技能包为 **灾难求生** 类型提供导演叙事与分镜表规则，核心关注：灾害升级、空间逃生、资源与时间压力、群体决策、人性选择。本手册**适用于任何视觉风格**，不覆盖 `art_skills` 中的画风、材质和渲染规则。

## 文件结构
```
Disaster_survival/
├── README.md
└── driector_skills/
    ├── director_planning_narrative.md
    └── director_storyboard_table_narrative.md
```

## 使用原则
- `director_planning_narrative.md`：解决“为什么这样拍、这一段要让观众知道/感受什么”。
- `director_storyboard_table_narrative.md`：解决“具体如何拆镜、如何保持信息/空间/动作连续”。
- 与视觉手册同时加载时，**叙事手册决定剧情与镜头功能，视觉手册决定画面媒介与风格表现**；二者不互相覆盖。
- 未明确的现实法律、医学、灾害处置、体育规则等事实不擅自编造。

## 研究依据
- BFI：灾难片以不同灾害为核心，具有稳定的类型结构；《海神号》式求生叙事的紧张感很大程度来自人物在被彻底改变的物理空间中移动。
- https://www.bfi.org.uk/lists/10-great-disaster-films
- https://www.bfi.org.uk/lists/10-great-shipwreck-films
