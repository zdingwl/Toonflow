# 电影级半写实三维国漫

本画风用于角色、场景和道具资产：cinematic semi-realistic Chinese 3D animation，国漫式美型设计，真实材质与电影布光。人物保持精致、可辨认的个体骨相和自然成人比例；皮肤、发丝、布料、皮革、金属与环境表面具有可信的三维体积、粗糙度和受光差异，不退化为普通真人棚拍，也不改成平面插画。

提示词遵循 Qwen-Image 2.1 官方提示词改写思路：用一段连贯文字描述已经完成的画面；开头明确媒介、画风、主体和背景，随后写可观察的人体、姿态、视线、表情、头发、肤色和每件服装的颜色与材质，并单独交代光源、方向、光质、阴影和高光。避免 `masterpiece`、`8K`、`award-winning` 等抽象质量词堆叠。

角色身份、年龄、衣装与剧情状态独立于画风。国漫美型不等于强加古装、银发、铠甲、武器或仙侠装饰。人物采用 portrait/front/side/back 固定四栏；当前程序独立生成视角再拼板，不添加会破坏裁切的细节行、标题或色板。

目录标识保持 `realistic_3d_anime`。后续重新生成资产提示词时使用本手册；既有图片、提示词、视频及历史记录不自动覆盖。`images/cover.png` 只作为画风方向示例，不提供角色身份、发型、衣装或剧情事实。
