# H3 四视图与对白语言升级（实施记录）

## 用户确定的方案

- 四视图质量由用户人工确认；系统不增加自动判定美术质量的强制门槛。四栏顺序固定：头像 / 正面全身 / 90°侧面全身 / 背面全身。
- H3 支持：整张四视图 BOARD（默认，一张 Picture、一名 Subject）；按镜头角度自动选择；手动选择独立参考视图。角色跨角度转身仍是同一个人物、同一个有效形态。
- 视频提示词可选 `original`、`zh-CN`、`en-US`、`en-GB`、`ja-JP` 等语言；默认保持剧本原语言。选择其他语言时仅翻译对白、发声旁白，原文保留，场景/人物/运镜说明不翻译。
- 切换语言先检查受影响片段的朗读预算。能够自然说完则保留镜头时长；不满足先局部重新安排停顿、对白或拆镜。禁止擅自延长整集，不强行超速朗读。
- 提示词阶段的参考图 ID、角色状态、视图角色、图片版本、实际 Picture 顺序必须与视频执行阶段一致；修改素材应使旧绑定失效。每一角色只能有一个当前有效状态，不能混用普通态和觉醒态。

## 本分支已提交的基础层

1. `src/utils/h3ReferenceSlots.ts`：完整四视图、自动角度和手动视图选择的纯逻辑。无镜头角度信息时不推断，退回 BOARD；超过九图拒绝。
2. `src/utils/assetReferenceMedia.ts`：默认保留完整四视图作为一张参考图，显式选择时按四栏裁切、附带源图指纹生成版本化文件名。图像合格与否仍由用户判断。
3. `src/utils/h3DialogueLanguage.ts`：受支持的语言/地区、提示词语言指令、估算语音时长及镜头超时提示的基础函数。
4. `data/modelPrompt/video/minimaxH3Multi-referenceMode.md`：同一个 Subject 的多视角、BOARD 禁止四宫格视频、对白语言与时长预算规则。
5. 新增或更新纯逻辑回归测试。
