# 真人3D动漫

本视觉手册用于生成具有成年真人结构基础的高品质 3D 动漫角色、场景、道具和镜头。所有资产以数字建模、造型归纳、材质设计和虚拟灯光为核心，形成统一、稳定、可复用的 CG 世界。

## 风格定位

- 真人骨相与自然人体比例，不使用幼态大头或夸张卡通变形。
- 3D 动漫化面部归纳：清晰面部块面、柔和转折、略强化的眼神设计，眼、鼻、嘴保持可信结构。
- 造型使用清楚的主轮廓与次级结构；表面细节按角色识别需要分级，视觉重心稳定。
- 材质采用经过美术设计的 PBR 响应：皮肤呈柔和渐变与受控次表面散射，头发呈成组发束，布料、皮革与金属具有清晰且克制的粗糙度差异。
- 灯光采用虚拟摄影棚或动画电影式灯光设计，主光、补光、轮廓分离和环境反弹关系明确，画面呈现干净的离线渲染质感。

## 适用范围

都市、爱情、成长、动作、幻想及跨类型的中高写实 3D 动漫项目；支持资产设定、分镜图和视频提示词。

## 交付边界

- 保持自然成年比例、克制动漫化程度、完整人体结构与统一 CG 材质语言。
- 保持表情自然、眼神聚焦、关节和接触关系准确、衣物与身体层次清楚。
- 交付画面保持干净，不含文字、水印和品牌标识。
