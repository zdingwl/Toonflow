# 现代都市国漫3D

本视觉手册以半写实美型国漫 3D 为目标，用于角色、场景、道具、分镜与视频提示词。保留自然骨相、精致数字角色造型、细密分层发丝、细腻皮肤、可信衣料与电影级光影。

## 衣装与题材

人物穿符合职业、场合和剧情的现代都市衣装，如衬衫、西装、皮衣、卫衣、牛仔裤或现代裙装。“国漫3D”描述渲染方式，不自动引入古装、仙侠、古代发型或未来朋克装饰。科幻与超自然元素只按明确剧情出现。

## 一致性

保留角色既有身份、年龄、体型、肤色、发型和衣装。参考图仅借鉴美术质感，不复制其人物身份或整套服装。资产图、分镜与视频共用同一风格，避免大眼圆脸卡通、塑料皮肤和整块头发。

目录标识仍为 `realistic_3d_anime`，供已有项目继续引用；原显示名称为“真人3D动漫”。新规则用于后续提示词生成，既有资产图、提示词与视频不会自动重生成。
