# 真人纪录片自然主义风格说明

本风格用于 Toonflow 的「真人纪录片自然主义」视觉与导演约束，目录结构与现有 art_skills 保持一致。

## 核心风格
- **媒介定位**：Live action；真人纪实摄影 · 自然主义表演
- **情感基调**：真实、克制、亲近、观察感
- **核心质感**：自然皮肤、真实环境材质、可见生活痕迹、不过度修饰的摄影质感
- **色彩方向**：遵循现场真实色温与材质色，中低饱和、肤色自然；仅在剧情明确需要时做显著风格化调色
- **光影原则**：自然光和practical light优先，必要时轻量补光；保留窗光、阴天、室内混合色温等现实特征
- **镜头原则**：观察式手持/肩扛、固定机位、缓慢跟随与较长镜头；手持抖动必须受控，不做故意眩晕

## 资产规则
- **角色**：真人比例和年龄感准确；妆发服装符合生活状态，表演以细小动作、停顿、视线和真实反应为主
- **场景**：优先真实可居住/可工作的空间，保留杂物、磨损、天气和现场光源逻辑；构图允许轻微不完美但信息清楚
- **道具**：现实物品按功能摆放，保留磨损、污渍、折痕和使用痕迹；不做广告式完美陈列
- **环境动态**：现场人声、风、交通、空调、餐具、布料、脚步等自然动态与环境声

## 严禁
- 商业广告式高光
- 过度磨皮
- 美颜滤镜
- 永远完美构图
- 无动机稳定器漂移
- 夸张电影雾和大面积特效光

## 研究依据
- 摄影规则采用观察式、自然光与有动机手持的通用纪录片语法；不绑定任何单一导演或工作室。
- Adobe/NFB 对动画媒介分类的资料也用于区分本类型与动画类型边界。

> 规则目标是提取可复用的媒介与摄影语言，不模仿具体在世创作者或单一工作室。
