# 真人3D动漫

本视觉手册用于生成兼具真人可信度与 3D 动漫审美的角色、场景、道具和镜头。角色保留真实成年人的骨相、年龄感、皮肤与发丝细节，同时采用克制的动漫化五官归纳、清晰轮廓和电影动画式表演；环境与物件遵循物理材质、真实尺度和可拍摄的光照逻辑。

## 风格定位

- 真人骨相与自然人体比例，不使用幼态大头或夸张卡通变形。
- 3D 动漫化面部归纳：眼神更有表现力，但眼、鼻、嘴仍服从真实结构。
- PBR 材质、皮肤次表面散射、发丝级毛发和电影级实时/离线渲染质感。
- 构图、灯光和景深服务叙事，成片明确是高品质 3D 动画而非真人照片。

## 适用范围

都市、爱情、成长、动作、幻想及跨类型的中高写实 3D 动漫项目；支持资产设定、分镜图和视频提示词。

## 禁止偏移

- 不得退化为真人摄影、纯二次元平涂、Q 版、塑料玩偶或低模游戏截图。
- 不得出现蜡像皮肤、过度磨皮、玻璃眼、僵硬表情、穿模和肢体畸形。
- 不模仿特定在世艺术家、导演或工作室；不生成文字、水印和品牌标识。
