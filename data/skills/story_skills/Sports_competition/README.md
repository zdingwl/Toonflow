# 体育竞技 · 导演叙事手法技能包

## 简介
本技能包为 **体育竞技** 类型提供导演叙事与分镜表规则，核心关注：训练成长、规则压力、团队关系、对手、竞争结果与人物价值。本手册**适用于任何视觉风格**，不覆盖 `art_skills` 中的画风、材质和渲染规则。

## 使用原则
- `director_planning_narrative.md`：解决“为什么这样拍、这一段要让观众知道/感受什么”。
- `director_storyboard_table_narrative.md`：解决“具体如何拆镜、如何保持信息/空间/动作连续”。
- 与视觉手册同时加载时，**叙事手册决定剧情与镜头功能，视觉手册决定画面媒介与风格表现**；二者不互相覆盖。
- 未明确的现实法律、医学、灾害处置、体育规则等事实不擅自编造。
