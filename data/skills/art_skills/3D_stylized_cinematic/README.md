# 风格化3D电影动画风格说明

本风格用于 Toonflow 的「风格化3D电影动画」视觉与导演约束，目录结构与现有 art_skills 保持一致。

## 核心风格
- **媒介定位**：3D；风格化建模 · 电影动画渲染
- **情感基调**：鲜明、亲和、戏剧化但不过分夸张
- **核心质感**：高质量3D模型、简化而可信的PBR材质、清晰轮廓、柔和全局照明
- **色彩方向**：允许完整电影色彩设计；同场景限定主色关系，避免无目的高饱和全屏轰炸
- **光影原则**：电影级主辅光、自然环境光、接触阴影与适度景深；光线服务叙事而非堆特效
- **镜头原则**：可用推拉摇移、轨道、升降和跟拍，但每次运动必须有叙事动机；动作镜头保持主体可读

## 资产规则
- **角色**：五官和体型可适度风格化，但骨骼、关节和动作逻辑可信；用轮廓、发型、服装色块和面部关键点锁定身份
- **场景**：完整三维空间，重视可读轮廓、块面关系和层次；材质简化但必须有真实粗糙度、反射和接触阴影
- **道具**：形体可适度夸张，但功能结构、尺度关系和材质属性必须清楚；避免无意义复杂机械细节
- **环境动态**：布料摆动、尘埃、树叶、水面、烟雾、灯光变化等可控环境动态

## 严禁
- 照片级真人皮肤
- 廉价塑料感
- 低模锯齿
- 无接触阴影
- 过度Bloom
- 无动机炫技镜头
- 特定在世艺术家/工作室模仿

## 研究依据
- Adobe：3D动画以数字模型、材质/纹理、骨骼绑定和渲染为核心流程。
- 参考：https://certifiedprofessional.adobe.com/blog/types-of-animation

> 规则目标是提取可复用的媒介与摄影语言，不模仿具体在世创作者或单一工作室。
