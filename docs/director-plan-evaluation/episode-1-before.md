### 逐场注意事项

- **Sc1**：
  - 情感砸点：麦迪逊一根根掰开艾娃抓栏杆的手指，最后一根脱开即失去支撑坠海——全场最高情感冲击。
  - 一致性锚点：艾娃一条腿受伤、双手在头顶抓固定栏杆、身体悬于船舷外无支撑；麦迪逊在其上方、身后只剩一个救生位置；严重倾斜邮轮、暴雨夜、远处半沉城市全程保持。
  - 空间距离/相对位置：麦迪逊位于艾娃上方且能直接触碰其手指；艾娃与甲板、救生位有明确高度差，避免拍成两人并排站栏杆旁；视线方向——艾娃向上求救、麦迪逊向下低头。
  - 动作施力与接触点：掰开的手指“最后脱开”必须为坠海的直接受力原因，接触点在栏杆与手指。
  - 环境音：暴雨砸甲板与船体、人群争抢声、风浪冲击船身。
  - 易错提示：鲨鱼从浪下冲出咬住受伤的腿，按血液与伤口约束处理——不出现红色血液/红色伤口，优先用浪涌遮挡、肢体剧烈挣扎与失重坠落表现，伤腿方向不以设定图站姿臆断。

- **Sc2**：
  - 情感砸点：艾娃意识模糊中望见上方邮轮，耗尽求生意志喊出“我要回去”后倒数归零回溯。
  - 一致性锚点：紧接 Sc1 坠海与被咬；蓝色系统文字按原文顺序出现——“海洋基建核心·07 / 宿主生命终止确认 / 时序锚点仍可连接 / 是否执行一次回溯？ / 3……2…… / 1”。
  - 空间距离：艾娃在水下，邮轮与麦迪逊只作为其主观视野上方的最后目标；倒计时文字贴近主观视野。
  - 环境音：水下闷响、气泡，呼吸声减弱。
  - 易错提示：原文“鲜血散开”不得画成红色血液/血雾/红色水体；如需呈现仅允许少量低饱和深绿色，并优先用波动水体、失焦视线与遮挡替代。Sc2 制作预算 22 秒 > 来源 20 秒，倒数 3、2、1 采用濒死延展主观时间，不锁成真实秒表速度。

- **Sc3**：
  - 情感砸点：艾娃不兴奋、不庆祝，先核对资产并连续拨电话备战，末句“这一次，我不等世界告诉我该逃了”转向主动掌控。
  - 一致性锚点：床猛然坐起；手机日期“灾变前72小时”；电视滚动新闻“近海异常高潮位，部分港区暂停夜间作业”；系统文字按序“核心07已重启 / 初始仓储：30m³ / 初始蓝图：一级应急浮台 / 距离第一轮极端风暴：71:58:41”；结尾黑屏。
  - 空间距离/相对位置：艾娃—床—手机—电视—窗外正常车流的屋内到城市层次；连续通话时以手机、账户/房产/车辆资料与倒计时为可见焦点。
  - 环境音：清晨拨号与接通提示声、窗外车流、电视播报声；台词密集需控制节奏。
  - 易错提示：五句均为艾娃自述，要区分自语与对电话两端下单；闪回“三天后断电、七天后抢水、四十七天后死亡”只服务判断、不新增剧情。倒计时首次按 71:58:41 呈示，后续如画面连续推进可随真实经过时间递减，不锁成固定值。制作预算 62.5 秒 ≠ 来源 50 秒，须按制作预算单独安排节奏，不擅自扩大。
