# 武侠江湖 · 导演叙事手法技能包

## 简介
本技能包为 **武侠江湖** 类型提供导演叙事与分镜表规则，核心关注：侠义选择、江湖秩序、门派/权力关系、武学对决、个人自由与责任。本手册**适用于任何视觉风格**，不覆盖 `art_skills` 中的画风、材质和渲染规则。

## 文件结构
```
Wuxia_martial_arts/
├── README.md

    ├── director_planning_narrative.md
    └── director_storyboard_table_narrative.md
```

## 使用原则
- `director_planning_narrative.md`：解决“为什么这样拍、这一段要让观众知道/感受什么”。
- `director_storyboard_table_narrative.md`：解决“具体如何拆镜、如何保持信息/空间/动作连续”。
- 与视觉手册同时加载时，**叙事手册决定剧情与镜头功能，视觉手册决定画面媒介与风格表现**；二者不互相覆盖。
- 未明确的现实法律、医学、灾害处置、体育规则等事实不擅自编造。

## 研究依据
- BFI：wuxia 源于中国文学传统，核心是“武/侠”，围绕持剑侠客、荣誉、正义、哲思与浪漫等展开。
- https://www.bfi.org.uk/lists/10-great-wuxia-swordplay-films
- BFI 对 King Hu 的分析：快速剪辑可传递高速动作，同时仍保持空间连续，并在对决中保留观察与停顿。
- https://www.bfi.org.uk/features/where-begin-with-king-hu
