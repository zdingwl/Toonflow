# 真人黑色电影悬疑风格说明

本风格用于 Toonflow 的「真人黑色电影悬疑」视觉与导演约束，目录结构与现有 art_skills 保持一致。

## 核心风格
- **媒介定位**：Live action；真人电影摄影 · 黑色电影悬疑
- **情感基调**：压迫、猜疑、克制、危险感
- **核心质感**：真实皮肤与服装材质、低调照明、高反差、深阴影、城市空间
- **色彩方向**：中低饱和冷中性色为主，可用钨丝暖光或局部城市色形成冷暖对照；不默认霓虹赛博朋克
- **光影原则**：low-key lighting、高反差明暗、实景光源与方向性侧/逆光；允许大片暗部但必须保留主体识别
- **镜头原则**：静镜、缓推、轨道、跟拍和必要的手持；镜头运动优先服务信息揭示、跟踪和心理距离变化

## 资产规则
- **角色**：保持真实人类比例、自然皮肤纹理与克制表演；通过眼神、呼吸、微表情和站位关系传递压力
- **场景**：城市夜景、室内走廊、办公室、车内、雨夜街道等均可，但由剧情决定；利用门框、百叶、反射、前景遮挡制造层次
- **道具**：现实世界材质与使用痕迹真实，关键道具用局部高光、构图或景深强调，不靠发光特效
- **环境动态**：雨水反光、烟雾/雾气、窗帘/百叶影、车灯扫过、远处交通、风吹纸张

## 严禁
- 全场均匀柔光
- 网红磨皮
- 无意义霓虹
- 赛博朋克替代黑色电影
- 过曝夜景
- 持续快速甩镜

## 研究依据
- BFI：film noir 常见城市空间、高反差照明和low-key lighting，并伴随怀疑、压抑等心理氛围。
- 参考：https://www.bfi.org.uk/features/genres-where-draw-line

> 规则目标是提取可复用的媒介与摄影语言，不模仿具体在世创作者或单一工作室。
