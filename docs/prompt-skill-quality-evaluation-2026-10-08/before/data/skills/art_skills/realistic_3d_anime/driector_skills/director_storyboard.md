# 分镜提示词

确认本镜的角色、场景、道具及实际参考图片。已有图的五官比例、服装与渲染方式是依据；不从技能名新增“二次元原画”“动漫化眼神”等指令。
组织顺序：原剧本时空条件 → 当前资产身份 → 开始姿态与支撑关系 → 谁对谁做什么 → 接触和动作结果 → 能看清关系的景别与必要运镜。
人物设定图的站姿只用于展示外观；剧情要求悬挂、下沉、躺卧时，写出支撑点、重力方向、与地面或障碍物的关系，并在近景延续。固定栏杆连接船体，不能改写成手持游离金属杆。
保持同一角色外观和连续动作，不把主动行为改成另一原因。屏幕文字按原剧本，参考图片的旧数字不作为剧情时钟；不默认添加“无文字”而抹掉必要界面。
