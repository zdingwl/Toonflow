# 分镜首帧提示词

适用于已配置的分镜图片模型。模型和参考输入能力以任务提供的实际配置为准，不因本技能默认改成 Seedream 或 Gemini，也不把 Qwen 的本地工作流当成云 API。

## 规则优先级

全局创作约束 → 当前任务模式与工具输出契约 → 分镜事实及当前有效参考 → 所选风格技法 → 本文示例。风格技法只补充表现，不改变人物身份、剧情、状态、画幅或引用顺序。图像模型的提示词不能混用 H3 的 `<Subject N>`、`<Picture N>`、六节格式或视频时间轴。

分镜画面是正文主干，保留可见主体、空间层次、必要道具、视线、情绪和动作因果；减少重复画质词，不用抽象“震撼、精致”替代事实。不从角色四视图带入陈列姿态、四栏布局、重复人物或白背景。

## 首帧转换

| 输入 | 静态图片中表达 |
|---|---|
| 已静止姿态/表情 | 原状态，如“停步仰望”“侧头冷笑”，不改成尚未发生 |
| 连续动作 | 该动作合理起始瞬间，写出实际接触与支撑，不输出多阶段动作链 |
| 远景→中景等运镜 | 箭头左侧的起始景别，不在静态图要求推拉运动 |
| 台词、VO、OS、音效 | 仅用于理解情绪，保存在 videoDesc，不画成字幕或放入图片正文 |
| 剧情屏幕/标牌文字 | 保留原文、载体和可读位置，与画外字幕区分 |

动作主体、受力对象、接触位置不能互换。悬挂、躺卧、下沉等以支撑和重力关系表达，不照搬参考图站姿。已悬挂的人在首帧就悬挂，不为“准备动作”改成站在边缘。

## 参考图绑定

1. 仅按本条实际图片输入顺序编号，资产 ID 不等于图序号。调用方传入 `associateAssetsIds` 时，与该顺序逐一对应；缺图不能静默跳号，先反馈缺失。
2. 前缀标注 `@图1 为角色A角色，@图2 为场景B场景…`，正文用同一标记指向该资产。类型包括角色、场景、道具等；不按类型重排，不引用本条没有输入的图片。
3. 说明每张图提供的角色身份、衣装、场景拓扑或道具形状；明确指定的剧情姿态优先于陈列姿态。当前目标状态明确改变的属性不能又要求保留默认值。
4. 参考图只继承已确认可见特征，不编不可见细节。风格从实际图与用户确定的表现方式取得，不从目录名叠加不兼容标签。

## 空间、朝向与构图

人物位置和朝向优先读取对应行字段，缺少独立列时从画面描述取得；仅在事实足够时补充简洁可见关系。保持世界坐标、轴线、视线、接触和动作进度；换机位后重新推导屏幕左右，不把全场角色锁死在画面同一侧。

镜中反射与现实主体朝向要同时自洽，不把镜中另一面当成第二人。身体、头部和目光方向分别描述，背对镜头但回头并不等于全身转向镜头。

景别按叙事主体取景：全景看清完整人物和必要接触点，远景侧重人景关系，近景呈现上半身，特写看清脸或关键局部。按项目画幅构图，不把所有模型或项目固定为竖屏。

## 输出格式与照明

- 向面板的字符串 `prompt` 写入一份可直接生成的正文，不输出推理、自检、说明或多个候选。
- 默认使用目标模型支持的自然语言：参考绑定 → 场景与构图 → 主体、姿态、空间和情绪 → 简短的身份/材质延续。调用方明确要求英文或 JSON 时才适配；JSON 是字符串内容而非新的工具参数，不擅自加 `negative` 字段或虚构 API 能力。
- 面板阶段的照明符合本场时段、天气和有效场景光源；允许简短描述受光、阴影、反射与材质关系来表现已确认的渲染目标，不强制另设【光影】段，不凭空增设光源或改变场景状态。剧本已有的屏幕亮起、闪光等视觉事件完整保留；参考的旧照明与明确目标状态矛盾时按目标描述并反馈必要参考缺项。
- 只排除画外字幕、水印和无关覆盖文字；不能用“no text / no UI text”抹掉必要手机界面、标牌、系统面板或倒计时。参考图旧数字服从本镜剧情。
- `global_content_constraints.md` 的非血腥表现优先于旧描写，保留事件因果并改写绘制描述。来源引文不改；正常红衣、红灯和非伤口肤色不变。限制放在内部上下文，最终正文只写自洽可见画面，不复述规则。

## 示例（仅说明语义转换）

输入：角色A已悬挂在栏杆外侧，手在头上抓握，脚下无支撑；全景，随后缓推。关联顺序为角色A、船侧场景。

正文：`@图1 为角色A角色，@图2 为船侧场景。全景首帧，@图1 身体悬在@图2 栏杆外侧，双手在头部上方抓握固定栏杆承重，双脚悬空，画面同时看清手、完整身体和脚下空间。延续参考的身份与衣装，栏杆与船体相连。`

示例的抓握手数、姿态和场景仅在输入明确要求时使用，不能套入其他镜头。

输出前逐项核对：本行语义完整、首帧状态合理、身体支撑自洽、图序与实际输入一致、状态唯一、画幅/景别正确、必要画内文字保留、照明符合当前时空与场景光源、无新增剧情。
