### 整集导演意图

**主导问题与目标 / 阻碍 / 代价**：主角艾娃能否在确认过的灾变时间线（三天后大停电、七天后抢水、四十七天后自己死亡，来源：Sc3 闪回）内提前完成撤离准备。目标：72 小时内卖车、短租偏远仓库、采购现货物资并开始备战；阻碍：时间窗口短、资源需现金与现货、灾变细节只有一则不起眼的新闻【近海异常高潮位，部分港区暂停夜间作业】；代价：若沿用前世的观望模式，下场就是 Sc1/Sc2 里手指被掰开、被鲨鱼咬住、意识熄灭。

**开场钩子（来源：Sc1 0–25 秒）**：用“半座城市沉在黑色海面里”的规模感 + “一位姐姐悬在船舷外、双手逐根被掰开”的具体动作 + 一句台词“麦迪逊，拉我上去！”建立危险、关系矛盾与反常信息——姐姐对妹妹的求救换来的是掰手指和“位置只有一个”。表现方法：不做世界观解说，先给艾娃悬空姿态与求生动作，再给麦迪逊在上方低头、身后只剩一个救生位置的空间关系；台词与“一根根掰开”并轨推进，不靠运镜制造伪冲突。

**中段推进与兑现（来源：Sc2 25–45 秒、Sc3 45–95 秒）**：Sc2 兑现“被咬—意识模糊—蓝色系统文字—倒计时 3、2、1—‘我要回去！’—白光”，给观众对命运变化的确认窗口（不是反转，而是对前 25 秒死亡结果的系统回应）；Sc3 兑现“重生 72 小时 + 核心07重启 + 初始仓储 30m³ + 一级应急浮台蓝图 + 倒计时 71:58:41”，并立刻把信息转化为行动：银行账户、房产估值、车辆资料、三通话（卖车 / 短租偏远仓库 / 现货采购）。先给观众“她没兴奋、先看家底”的反向反应，再给三通话的快速推进，最后用“这一次，我不等世界告诉我该逃了”作为对整段行动的宣言性收束。表现方法：倒计时与系统文字贴主观视野、不抢对白；三通话之间用“下一通”“再下一通”的语气推进，不用换景或配乐堆节奏。

**结尾追看点（来源：Sc3 末句）**：黑屏前的“这一次，我不等世界告诉我该逃了”把本集从“濒死回溯”推进到“主动备战”：观众追的是 71:58:41 倒计时下的三条线——现金能否到位、仓库租到多偏远、工业滤芯 / 移动储水罐 / 救生设备现货能否成交；以及麦迪逊这条关系线是否会在 72 小时内再次出现（不新增下一集剧情、仅保留原已存在的人物）。闭合方式是“她已拨出三通话 + 一句宣言”，不是悬念硬造。

**节奏线（三场串联）**：
- Sc1｜高密度求救→被掰→坠海→被咬，25 秒内把“被抛弃 + 死亡 + 变异威胁”一次性钉死，情绪浓度 10。
- Sc2｜水下主观视野慢下来，蓝色文字覆盖、倒计时 3/2/1 用濒死时间伸展，最后一句“我要回去！”把情绪从“涣散”拉到“强撑求生意志”，白光爆开收束，情绪浓度 9。
- Sc3｜醒来后先给一段“反兴奋”冷静节拍（看手机日期、看新闻、看窗外车流、看回忆），再用五句话把“确认—决定—下单—下单—下单—宣言”跑完，最后一句黑屏留白。整体是“爆发→下沉→冷静反弹”的锯齿，不是持续拉满。

### 逐场导演设计

#### Sc1：外·倾斜邮轮·暴雨夜（0–25 秒，预算 25 秒）

- **场景任务**：艾娃想被拉上甲板（目标：活过这一秒），被麦迪逊以“只有一个救生位置”为由掰开手指（阻碍：位置稀缺 + 情感背叛），离场时失去全部支撑坠入黑色海面并被变异鲨咬住伤腿（局势：从“还能被救”变为“已被主动抛弃 + 生物威胁”，主动权彻底交出）。
- **冲突 / 潜台词（标注推断）**：表层是位置争夺；潜台词（推断）是麦迪逊把“想活”当作唯一合法动机，用一句话把“救姐姐”从道德义务降格为资源竞争——观众读到的不是冷血，而是被恐惧驱动的自私。
- **进入 → 离开状态**：进入时艾娃双手已抓紧栏杆、一条腿受伤、身体悬在船舷外；离开时手指全部脱开、身体落入黑色海面、双腿被变异鲨咬住，画面以浪涌遮挡收束。
- **观众视点与表演基调**：跟艾娃的“被救 → 被剥夺 → 被抛入 → 被咬”四条动作线；麦迪逊的“求救对象 → 施力者 → 独自占位”身份切换用她的身体重心和手部动作呈现，不靠旁白。基调：求救急促 → 掰指时短暂僵直 → 脱手瞬间的失语 → 入水后的挣扎。

**连续性锚点**：
- 艾娃开场即悬在船舷外、双脚无支撑、双手在头顶抓紧栏杆、一条腿受伤（已被旧锚点确认，不改为先站立后被推倒）。
- 麦迪逊在艾娃上方且能直接触碰她的手；两人之间存在明确高度差，不能拍成并排站栏杆旁。
- “身后只剩一个救生位置”是空间事实，需在同一景别内可见。
- 巨鲨咬住的是“她的腿”且是“一条腿受伤”的那条，动作因果：掰开所有手指→脱手→坠海→鲨从浪下→咬住伤腿。
- 血液表现遵守全局约束：本集不呈现红色血液；鲨咬伤处以衣物覆盖 + 浪涌遮挡 + 挣扎姿态呈现，如需表面痕迹仅低饱和深绿色。

**制作风险与并行关系**：
- B2 的“逐根掰指”是连续手部动作 + 台词并行的密集段：4 条台词（24 字）+ 一根根掰开的动作需要 7 秒内完成，台词不能压过手部动作可读性；建议麦迪逊两句短台词落在第 1 根、第 3 根指脱手瞬间，艾娃两句短台词分别对应“开始掰”和“即将脱手”的节点。
- B3 的“坠海 + 鲨咬”是不可逆动作：需先看到手指全部脱开，再看到身体下坠，再看到鲨从浪下，再看到咬住——四个因果节点都必须可读，不能合并为一个大远景糊过。
- 环境音：暴雨砸甲板、甲板争抢、风浪冲击船身与雨声；入水后 3 秒内切为水下闷响，为 Sc2 声音做桥接。

- **场景任务**：艾VA在濒死中（障碍：生命终止、身体已被咬）确认自己还能回溯（目标：抓住系统给的唯一一次机会），离场时“我要回去！”喊出、倒计时到 1、白光爆开（局势：从“正在死”转为“被系统强制拉回”，主动权短暂回到艾VA手中）。

#### Sc3：内·艾VA公寓·清晨（原 45–95 秒，预算 62.5 秒）

- **场景任务**：艾VA（障碍：刚从死亡回溯、只有 72 小时、资源未到位）确认自己重生的现实（目标：把“回去”从愿望变成行动），离场时完成三通话（卖车 / 短租偏远仓库 / 现货采购）并说出“这一次，我不等世界告诉我该逃了”（局势：从“被命运拖到死亡”转为“主动掌握 72 小时”，主动权回到艾VA手中）。
