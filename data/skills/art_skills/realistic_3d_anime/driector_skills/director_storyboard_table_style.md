# 分镜表约束 · 现代都市国漫3D

- 每镜明确景别、机位高度、焦段倾向、主体动作、视线、光源方向、环境动态和镜头运动。
- 人物始终保持真人骨相、自然人体比例与同一身份；半写实国漫造型保持克制眼脸比例与细密分层发丝，现代都市衣装与角色设定一致，不改变年龄或脸型。
- 对话镜头保留呼吸、眨眼、吞咽、视线转移和反应时间；口型、下颌、面颊与声线节奏协调。
- 动作拆为准备、发力、接触、惯性与收束；脚底受力、衣料褶皱、头发延迟和道具反馈符合物理。
- 光源方向、色温、阴影、天气、空间轴线和道具位置跨镜连续。
- 运镜从角色或叙事动机出发，使用稳定推拉、轨道、摇移、跟随或受控手持；禁止无动机炫技。
- 转场优先动作匹配、视线匹配、声音桥、遮挡或光色变化，不用随机特效遮盖空间断裂。
