# 中国剪纸动画风格说明

本风格用于 Toonflow 的「中国剪纸动画」视觉与导演约束，目录结构与现有 art_skills 保持一致。

## 核心风格
- **媒介定位**：2D / Stop-motion；民间剪纸 · 纸偶定格质感
- **情感基调**：质朴、民俗、装饰性、节奏鲜明
- **核心质感**：可见纸纤维、剪切边缘、层叠纸片、关节式纸偶、轻微实体投影
- **色彩方向**：朱红、墨黑、米白、土黄、靛青等民间色为基础，可按剧情扩展但避免荧光色
- **光影原则**：均匀柔光或背光纸影，强调纸片层次和边缘，不使用复杂镜头炫光
- **镜头原则**：以固定机位、平移、轻推和舞台式横向调度为主；动作体现逐格定格的轻微节奏感

## 资产规则
- **角色**：角色以清晰剪影、侧面/半侧面轮廓和镂空纹样建立识别；肢体可采用纸偶关节结构，但比例必须稳定
- **场景**：二维舞台式分层空间，前中后景由纸片层级、遮挡和轻微投影区分；可吸收年画、皮影、民间纹样语言
- **道具**：功能造型以剪纸轮廓和镂空纹样表现，边缘切口与纸张层叠清晰，不伪装为塑料或3D模型
- **环境动态**：纸片云层、剪纸花叶、灯影、窗花投影、旗幡、纸屑/落叶

## 严禁
- 光滑矢量扁平图
- 无纸张纤维的纯数字贴片
- 写实3D
- 赛博霓虹
- 过度景深
- 液态渐变

## 研究依据
- NFB：cut-out animation 使用纸、卡纸或织物等二维材料，逐步移动并逐帧拍摄。
- 参考：https://blog.nfb.ca/blog/2018/06/14/animation-techniques-cutout/
- M+：中国剪纸动画可吸收传统皮影戏等视觉语言。
- 参考：https://www.mplus.org.hk/sc/cinema/animation-pioneers-in-asia/mainland-china-revisiting-the-classics/

> 规则目标是提取可复用的媒介与摄影语言，不模仿具体在世创作者或单一工作室。
