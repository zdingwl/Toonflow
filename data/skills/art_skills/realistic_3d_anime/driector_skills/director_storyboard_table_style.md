# 分镜表连续性

- 角色图提供脸型、五官比例、年龄和衣装，场景图提供空间结构；渲染沿用已确认项目画风与表现目标，不继承历史图片的风格偏差或由题材新增风格。照明符合本场时段、天气和已有光源，可用简短受光、阴影及材质关系落实电影表现，不凭空增加光源、改变场景状态或增添配乐。
- 每镜说明可见开始状态、行动与结束状态；接触、失衡或支撑改变时才具体写施力者、接触对象和支撑点。悬挂时交代手承重、身体与障碍物关系、脚是否触地；参考图的展示姿势不等于剧情动作。
- 保持栏杆与船体、门与墙等固定结构的连接关系。用能看到关键关系的景别建立空间，再进入手部或面部特写。
- 多角色动作保留施力者与受力者，不把主动掰开改成自然滑脱。近景承接前镜支撑状态，不因只拍脸而恢复站姿。
- 对白允许按语义拆镜，但同一说话人的原文和顺序完整保留；画外音明确标记，不凭声音增加出镜人物。
- 身份图和场景图不决定动作、相机角度。衍生图状态必须符合剧情；同一手机的不同界面是一台设备，明确先后切换或同屏显示。
- 屏幕图提供界面样式，显示内容以剧本原文为准。倒计时按连续时间推进，主观慢镜须注明，不能在后镜重新从旧数字开始。
