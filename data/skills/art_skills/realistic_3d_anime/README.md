# 精品二次元写实原画

依据用户认可的角色设定板方向：premium anime-realistic concept art、polished illustration rendering、clean premium shading。目标是精致风格化面部、柔和插画明暗、可读且有秩序的衣装细节；角色、场景、道具采用此资产绘制方向；视频使用 video_prefix.md 的电影级半写实三维渲染目标，继承资产身份和设计。

角色身份、年龄、衣装与剧情状态独立于画风。幻想原画不等于强加古装、银发、铠甲、冰雪或武器。人物采用低干扰冷灰蓝背景及portrait/front/side/back固定四栏；当前程序独立生成视角再拼板，不添加会破坏裁切的细节行和色板。

目录标识保留 realistic_3d_anime，已有项目继续使用同一路径。新规则在后续重新生成提示词时生效，既有图片、提示词、视频及历史不自动覆盖。images/cover.png 是旧版展示封面，不作为新画风的生成依据；以本手册和用户提供的明确风格参考为准。
